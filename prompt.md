# i mie prompt 
## 1 : un sitto
prima : fammi un sitto
doppo : Act as an expert front-end developer and Italian language teacher for foreign learners.

Build a one-page static website for learning Italian.

Context:
- Target: Italian for foreign speakers.
- The vocabulary words are already available or provided by the user or teacher. Insert the word list here: INSERISCI QUI LE PAROLE.
- If no words are provided, generate a starter deck of 20 A1 words or phrases.

Design:
- One page only.
- White background.
- Clean, minimal, accessible, responsive, mobile-first.
- No backend, no build step, static files.
- Progress saved in localStorage, no server. Fallback to memory. Add reset progress button.

Features:
1. Flashcard di vocabolario
- Use the provided words or the generated deck.
- Card front: Italian word or phrase, pronunciation, part of speech.
- Card back: English translation, example sentence, example translation, note.
- Controls: flip card, next or previous, mark known or unknown.

2. Quiz a scelta multipla
- Create 10 multiple-choice questions from the flashcard deck.
- One correct answer, 3 distractors.
- Immediate feedback and brief explanation.
- End screen: score, retry button.

3. Mini-lezioni con dialogo e traduzione
- Create 3 short dialogues for foreign learners.
- Show Italian dialogue line by line.
- Toggle English translation.
- Highlight vocabulary.
- Add simple comprehension questions.

4. Esercizi di coniugazione
- Present tense exercises for common verbs: avere, essere, fare, dire, and 5 regular verbs.
- Use fill-in-the-blank or multiple choice.
- Immediate feedback.

Progress:
- Save to localStorage, no server.
- Track flashcard status, quiz best score, lesson progress, conjugation attempts.
- Add reset progress button.

Deliverable:
- Complete code for the one-page app.
- No backend, no build step, static files.
- Ensure all features work.

Target level: INSERISCI LIVELLO, ESISTE A2 O B1.
Words source: INSERISCI QUI LE PAROLE O GENERA DECK BASE.
